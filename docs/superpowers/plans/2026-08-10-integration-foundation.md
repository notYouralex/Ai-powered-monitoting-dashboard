# Shared Integration Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the minimal shared dependency, configuration, HTTP transport, request-ID, safe-error, and router foundation required for Wazuh and Zabbix development to proceed independently.

**Architecture:** Keep source semantics inside owned integration packages. Shared code owns only source-prefixed configuration, HTTP client construction and opt-in retry behavior, request tracing, safe source errors, and one-time FastAPI router wiring. Missing source credentials resolve to `not_configured` and never prevent global application startup.

**Tech Stack:** Python 3.12+, FastAPI, Pydantic v2 / pydantic-settings, httpx 0.28-compatible APIs, pytest, uv.

## Global Constraints

- Source integrations remain read-only; this plan adds no real source calls or source-write capabilities.
- No monitoring, asset, or ticket data may leave the company network.
- TLS verification defaults to `true`; an explicit CA bundle is preferred for internal/self-signed certificates.
- In `APP_ENV=production`, a configured source with `*_VERIFY_TLS=false` is invalid configuration.
- Source timeout default is 10 seconds; accepted range is 1–60 seconds.
- Shared HTTP clients use at most 20 total connections and 10 keep-alive connections.
- Shared User-Agent is exactly `ai-powered-monitoring-dashboard/0.1`.
- Retry behavior is opt-in; retry-safe operations allow at most two retries after the initial attempt.
- Retryable HTTP statuses are exactly 429, 502, 503, and 504.
- Retryable transport exceptions are connection establishment failure and connection timeout.
- Retry delays are exactly 0.25 seconds, then 0.5 seconds.
- Incoming `X-Request-ID` is reused only when it matches `[A-Za-z0-9._-]{1,64}`; otherwise generate lowercase UUID4 hex.
- Public integration error codes are `SOURCE_NOT_CONFIGURED`, `SOURCE_AUTH_FAILED`, `SOURCE_UNAVAILABLE`, `SOURCE_RATE_LIMITED`, and `SOURCE_BAD_RESPONSE`.
- No passwords, API keys, bearer/JWT tokens, Authorization headers, connection strings, stack traces, or raw source bodies may appear in public error responses.
- Environment variable prefixes are exactly `WAZUH_`, `ZABBIX_`, `SNIPE_IT_`, and `FRESHSERVICE_`.
- No database migrations, worker, Grafana, AI, CI, CODEOWNERS, Docker service additions, Wazuh configuration changes, service restarts, firewall/network changes, `sudo`, or pushes are part of implementation.
- Work only on `feature/integration-foundation`; do not implement directly on `main`.

Create `app/core/request_id.py`:

```python
import re
from uuid import uuid4

from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request

REQUEST_ID_HEADER = "X-Request-ID"
_REQUEST_ID_PATTERN = re.compile(r"^[A-Za-z0-9._-]{1,64}$")


def normalize_request_id(value: str | None) -> str:
    if value is not None and _REQUEST_ID_PATTERN.fullmatch(value):
        return value
    return uuid4().hex


class RequestIdMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        request_id = normalize_request_id(request.headers.get(REQUEST_ID_HEADER))
        request.state.request_id = request_id
        response = await call_next(request)
        response.headers[REQUEST_ID_HEADER] = request_id
        return response
```

Create `app/core/errors.py` with exact public types and controlled messages:

```python
from typing import Literal

from fastapi import Request
from fastapi.responses import JSONResponse

from app.contracts import IntegrationSource

IntegrationErrorCode = Literal[
    "SOURCE_NOT_CONFIGURED",
    "SOURCE_AUTH_FAILED",
    "SOURCE_UNAVAILABLE",
    "SOURCE_RATE_LIMITED",
    "SOURCE_BAD_RESPONSE",
]

_STATUS_BY_CODE = {
    "SOURCE_NOT_CONFIGURED": 503,
    "SOURCE_AUTH_FAILED": 502,
    "SOURCE_UNAVAILABLE": 503,
    "SOURCE_RATE_LIMITED": 503,
    "SOURCE_BAD_RESPONSE": 502,
}

_SOURCE_NAMES = {
    "wazuh": "Wazuh",
    "zabbix": "Zabbix",
    "snipe_it": "Snipe-IT",
    "freshservice": "Freshservice",
}

_MESSAGE_BY_CODE = {
    "SOURCE_NOT_CONFIGURED": "{source} is not configured.",
    "SOURCE_AUTH_FAILED": "{source} authentication failed.",
    "SOURCE_UNAVAILABLE": "{source} is temporarily unavailable.",
    "SOURCE_RATE_LIMITED": "{source} is temporarily rate limited.",
    "SOURCE_BAD_RESPONSE": "{source} returned an unusable response.",
}


class IntegrationError(Exception):
    def __init__(
        self,
        *,
        source: IntegrationSource,
        code: IntegrationErrorCode,
        retryable: bool,
    ) -> None:
        super().__init__(code)
        self.source = source
        self.code = code
        self.retryable = retryable


def integration_error_handler(request: Request, exc: IntegrationError) -> JSONResponse:
    request_id = getattr(request.state, "request_id", "")
    message = _MESSAGE_BY_CODE[exc.code].format(source=_SOURCE_NAMES[exc.source])
    return JSONResponse(
        status_code=_STATUS_BY_CODE[exc.code],
        content={
            "error": {
                "code": exc.code,
                "message": message,
                "source": exc.source,
                "retryable": exc.retryable,
                "request_id": request_id,
            }
        },
    )
```

Do not add arbitrary public-message or raw-exception parameters to `IntegrationError`; the controlled message map is the secret-leak prevention boundary.

def _build_verify(verify_tls: bool, ca_bundle: str | Path | None):
    if not verify_tls:
        return False
    if ca_bundle is not None:

- [ ] **Step 4: Implement explicit retry behavior**

Add to `app/core/http.py`:

```python
async def request_with_retries(
    client: httpx.AsyncClient,
    method: str,
    url: str,
    *,
    retry_safe: bool = False,
    **kwargs,
) -> httpx.Response:
    max_attempts = 3 if retry_safe else 1

    for attempt in range(max_attempts):
        try:
            response = await client.request(method, url, **kwargs)
        except (httpx.ConnectError, httpx.ConnectTimeout):
            if attempt + 1 >= max_attempts:
                raise
            await asyncio.sleep(RETRY_DELAYS[attempt])
            continue

        should_retry = retry_safe and response.status_code in RETRYABLE_STATUS_CODES
        if not should_retry or attempt + 1 >= max_attempts:
            return response

        await asyncio.sleep(RETRY_DELAYS[attempt])

    raise RuntimeError("retry loop exited without response")
```

Do not infer retry safety from `GET` versus `POST`; `retry_safe=True` is the only switch.
